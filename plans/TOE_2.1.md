Sorkin's cosmological constant conjecture (\(\Delta \Lambda \sim 1/\sqrt{V}\)) relies strictly on the Poisson fluctuations of fundamentally discrete spacetime atoms unique to Causal Set Theory

I think **Poisson fluctuations can provide a surprisingly clean statistical bridge** among CST, CDT, Bohmian QFT, and asymptotic safety—but only if we use Poisson statistics for what they actually provide: **number–volume fluctuations**, not as a universal dynamical law.

The key thought experiment is:

\[
\boxed{
N(V)\sim \operatorname{Poisson}(\rho V)
}
\]

so that

\[
\boxed{
\langle N\rangle=\rho V,\qquad
\operatorname{Var}(N)=\rho V,\qquad
\delta N\sim\sqrt N,\qquad
\frac{\delta N}{N}\sim\frac1{\sqrt N}.
}
\]

This number–volume correspondence is one of the reasons Poisson sprinkling is central to CST: it gives a way of representing continuum volume by discrete causal-set cardinality while preserving Lorentz symmetry in the continuum approximation. [arXiv](https://arxiv.org/abs/1403.6429?utm_source=chatgpt.com)

# 2. CST: Poisson gives the Stage its number–volume relation

Imagine a continuum spacetime region of four-volume \(V\).

CST says, schematically:

\[
N\sim\operatorname{Pois}(\rho V).
\]

Therefore

\[
V\approx \frac{N}{\rho}
\]

only statistically.

This gives the Stage an intrinsic fluctuation:

\[
\frac{\delta V}{V}\sim\frac1{\sqrt N}.
\]

At enormous \(N\), spacetime looks smooth.

At small \(N\), discreteness is unavoidable.

That produces an extremely natural interpolation:

\[
\boxed{
N\gg1\Rightarrow\text{continuum geometry}
}
\]

\[
\boxed{
N\sim1\Rightarrow\text{quantum/discrete geometry}.
}
\]

This is genuine CST logic, although **Poisson sprinkling itself should not be confused with CST dynamics**. CST has separate dynamical laws for causal sets. [arXiv](https://arxiv.org/abs/1903.11544?utm_source=chatgpt.com)

\[
\boxed{

\Psi_C
\rightarrow

Across possible causal histories:

\boxed{
\text{Bohmian indeterminacy}

\text{geometric ensemble fluctuations}.

The former is about the actual configuration given the state.

The latter is about which underlying causal geometry/history is realized or sampled.
